## ✨ Features

- 🖌️ **Brush & Eraser** — smooth freehand drawing with adjustable size
- 🔷 **Shapes** — rectangle, circle, triangle (with optional fill)
- 🎨 **Color palette** — 10 preset colors + custom color picker
- ↩️ **Undo / Redo** — with `Ctrl+Z` / `Ctrl+Y` shortcuts
- 💾 **Export as PNG** — save your artwork in one click (`Ctrl+S`)
- 🖱️ **Pointer Events** — works seamlessly with mouse, touch, and stylus
- 🖥️ **Retina-ready** — crisp lines on high-DPI screens
- 📱 **Fully responsive** — desktop, tablet, and mobile
- 🌙 **Modern dark UI** — clean, minimal, distraction-free

## 🧠 What I Learned

Building PoyberPaint helped me practice:

- **Canvas API** — `getImageData`, `putImageData`, `stroke`, `fill`, transforms
- **Pointer Events** — unified mouse/touch/stylus handling
- **DPR-aware rendering** — crisp output on retina displays
- **State management** — undo/redo stack without a framework
- **Debouncing** — smooth canvas resize
- **Modular architecture** — clean separation of concerns in vanilla JS

## 📦 Getting Started

```bash
git clone https://github.com/ashkanpoyber/PoyberPaint.git
cd PoyberPaint
```

Then just open `index.html` in your browser. No build step needed.

Or run a local server:
`npx serve .`
